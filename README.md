# Shubham Desai — AI Portfolio

A modern, premium portfolio website built with React, Tailwind CSS, and Framer Motion.

## Features

- AI-themed loading animation with futuristic transition
- Dark theme with glassmorphism effects
- Fully responsive design
- Animated sections with Framer Motion
- SEO optimized meta tags

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Resume

Place your resume PDF at `public/resume.pdf` for the "Download Resume" button to work.

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- Lucide React Icons
